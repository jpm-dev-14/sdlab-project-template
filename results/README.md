# Results

Generated by `make load` and `make results`; never edited by hand.

- One JSON file per run: `<UTC timestamp>-<profile>-<short git sha>.json`. Each records the git SHA, hardware, container limits, load parameters, latency percentiles, errors and the invariant checker's verdict.
- `charts/` holds charts generated from those files.
- A run from a dirty working tree, or with the load generator above 80% CPU, isn't cited anywhere.

ADRs, the README and the blog post cite these files by path.
